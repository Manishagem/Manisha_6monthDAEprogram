# Version Control Fundamentals

This module focuses on best practices for version control using Git, including staging, committing, and branching strategies.

## Contents

| Item | Description |
| :--- | :--- |
| `RollADie.py` | Sample script used to demonstrate versioning and change tracking. |

## Common Git Commands

Use these commands to manage changes within this module:

```bash
# Check the status of your files
git status

# Stage changes for commit
git add RollADie.py

# Commit changes with a descriptive message
git commit -m "Add roll-a-die simulation script"

# View the commit history
git log --oneline
```

For more advanced workflows, refer to the [Git Documentation](https://git-scm.com/doc).
