## Commands demonstrated

| Command | What it does | Used in the screenshot to |
|---------|--------------|---------------------------|
| `cd Desktop` | Change directory | Move into the Desktop folder |
| `pwd` | Print the working directory | Confirm the current location |
| `ls` | List files | See what is on the Desktop |
| `ls -a` | List including hidden files | Reveal items such as `.DS_Store` |
| `ls -la` | Long listing, including hidden files | Show permissions, owners, sizes, and dates |
| `touch test.txt` | Create an empty file | Make a new text file |
| `nano test.txt` | Edit a file in the terminal | Type a line of text into it |
| `cat test.txt` | Print a file's contents | Check what was saved |
| `cd Manisha_6months_DAE_Project` | Enter the project folder | Move into the Git repository |
| `git status` | Show changed and untracked files | See `GoFit.py` modified and `testFile.py` untracked |
| `git add .` | Stage all changes | Prepare them for a commit |
| `git commit -m "Add code to GoFit.py"` | Save a snapshot with a message | Record the change |
| `git push --all` | Upload branches to GitHub | Publish the commit |
