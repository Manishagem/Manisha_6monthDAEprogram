# Prompt Engineering

Resources and techniques for optimizing interactions with Large Language Models (LLMs).

## Core Resources

| Resource | Description |
| :--- | :--- |
| `Prompt.pages` | A curated collection of prompts and engineering strategies for improved AI responses. |

## Techniques Explored

- **Few-Shot Prompting**: Providing examples to guide model output.
- **Chain-of-Thought**: Encouraging step-by-step reasoning.
- **System Instructions**: Defining persona and constraints for the model.
