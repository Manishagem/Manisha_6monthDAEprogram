# EISP IAM

This folder contains Terraform configurations for managing Identity and Access Management (IAM) within the Enterprise Identity Security Platform (EISP). Key files include:
- `.gitignore`: Specifies intentionally untracked files to ignore.
- `.terraform.lock.hcl`: Terraform dependency lock file.
- `authentik-metadata.xml`: XML metadata for Authentik integration.
- `main.tf`: Main Terraform configuration file.
- `outputs.tf`: Terraform output definitions.
- `variables.tf`: Terraform variable definitions.
