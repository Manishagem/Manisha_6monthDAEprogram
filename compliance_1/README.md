# Compliance

This folder contains documents related to compliance within the EISP (Enterprise Identity Security Platform). Key documents include:
- `01-EISP-compliance-fundamentals.docx`: Covers fundamental concepts of compliance.
- `02-EISP-compliance-program-development.docx`: Details the development of compliance programs.
- `03-EISP-compliance-auditing-basics.docx`: Explains the basics of compliance auditing.
- `04-EISP-documentation-reporting.docx`: Focuses on documentation and reporting for compliance.
- `05-EISP-legal-ethical-implementation.docx`: Discusses the legal and ethical implementation aspects of compliance.
