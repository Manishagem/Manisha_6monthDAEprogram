# Sass Stylesheets

This folder contains Sass (Syntactically Awesome Style Sheets) files used for styling the website. Key files include:
- `fonts.scss`: Styles related to custom fonts.
- `jekyll-theme-minimal.scss`: Main Sass file for the Jekyll Minimal theme.
- `minimal.scss`: Core minimal styles.
- `rouge-github.scss`: Styles for Rouge (syntax highlighter) with a GitHub theme.
