# Utility Scripts

This folder contains various shell scripts for managing the project lifecycle, from environment setup to deployment and validation.

## Available Scripts

| Script | Purpose |
| :--- | :--- |
| `bootstrap` | Sets up the initial project environment and dependencies. |
| `cibuild` | Runs continuous integration tests and build processes. |
| `release` | Handles project versioning and release management. |
| `validate-html` | Validates the generated HTML files for standards compliance. |

## Usage

Ensure the scripts have execution permissions before running them:

```bash
# Grant execution permissions
chmod +x script/*

# Run the bootstrap script
./script/bootstrap
```
