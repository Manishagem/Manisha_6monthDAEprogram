# Noto Sans Italic

This folder contains the Noto Sans font in italic style, with various file formats for web usage:
- `Noto-Sans-italic.eot`: Embedded OpenType font for older Internet Explorer versions.
- `Noto-Sans-italic.svg`: SVG font for older iOS devices.
- `Noto-Sans-italic.ttf`: TrueType Font.
- `Noto-Sans-italic.woff`: Web Open Font Format for modern browsers.
- `Noto-Sans-italic.woff2`: WOFF2 font, offering better compression and performance.
