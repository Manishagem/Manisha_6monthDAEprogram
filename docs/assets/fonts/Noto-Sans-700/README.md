# Noto Sans 700

This folder contains the Noto Sans font in bold (700) weight, with various file formats for web usage:
- `Noto-Sans-700.eot`: Embedded OpenType font for older Internet Explorer versions.
- `Noto-Sans-700.svg`: SVG font for older iOS devices.
- `Noto-Sans-700.ttf`: TrueType Font.
- `Noto-Sans-700.woff`: Web Open Font Format for modern browsers.
- `Noto-Sans-700.woff2`: WOFF2 font, offering better compression and performance.
