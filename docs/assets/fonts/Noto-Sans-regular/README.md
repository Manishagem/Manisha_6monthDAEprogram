# Noto Sans Regular

This folder contains the Noto Sans font in regular weight, with various file formats for web usage:
- `Noto-Sans-regular.eot`: Embedded OpenType font for older Internet Explorer versions.
- `Noto-Sans-regular.svg`: SVG font for older iOS devices.
- `Noto-Sans-regular.ttf`: TrueType Font.
- `Noto-Sans-regular.woff`: Web Open Font Format for modern browsers.
- `Noto-Sans-regular.woff2`: WOFF2 font, offering better compression and performance.
