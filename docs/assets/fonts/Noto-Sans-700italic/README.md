# Noto Sans 700 Italic

This folder contains the Noto Sans font in bold italic (700 italic) weight, with various file formats for web usage:
- `Noto-Sans-700italic.eot`: Embedded OpenType font for older Internet Explorer versions.
- `Noto-Sans-700italic.svg`: SVG font for older iOS devices.
- `Noto-Sans-700italic.ttf`: TrueType Font.
- `Noto-Sans-700italic.woff`: Web Open Font Format for modern browsers.
- `Noto-Sans-700italic.woff2`: WOFF2 font, offering better compression and performance.
