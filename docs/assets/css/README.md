# Stylesheets

This directory contains the CSS and SCSS files that define the visual presentation of the project's documentation site.

## Key Files

| File | Description |
| :--- | :--- |
| `style.scss` | The primary entry point for styles, importing Sass partials and compiling into the main stylesheet. |

## Customization

To modify the theme, edit the SCSS files in this directory or the corresponding partials in the [`_sass`](../../_sass/) folder.
